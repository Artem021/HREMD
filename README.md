About
This repository contains code for HREMD simulations in LAMMPS.

Installation
1. Use 'git clone https://github.com/Artem021/HREMD.git -b clean' to get a copy of repository.
2. Make sure you have Python 3.7+ with pandas and numpy packages installed.
3. Make sure you have LAMMPS revision 2nd Aug 2023 or later.

Usage
Edit config.json, specify path to folder with LAMMPS binaries and to your LAMMPS data file.
Run 'python main.py' to start simulation or submit it to SLURM (use calc.sh as example).
