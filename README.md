## About

This repository contains code for HREMD simulations in <span style="background-color: #FFFF00">LAMMPS</span>.

## Installation

1. Make sure you have Python 3.7+ with pandas and numpy packages installed.
2. Make sure you have LAMMPS revision 2nd Aug 2023 or later.
3. Use `git clone https://github.com/Artem021/HREMD.git -b clean` to get a copy of repository.

## Usage

Edit config.json, specify path to folder with LAMMPS binaries and to your LAMMPS data file.
Run 'python main.py' to start simulation or submit it to SLURM (use calc.sh as example).
